# Historical notebook archive

`road_safety_dissertation_coding_historical.ipynb` is an earlier Colab execution
log retained only for provenance. It records setup and data-availability
troubleshooting from before the validated analysis-ready dataset was published,
so its saved `FileNotFoundError` cells are expected and it must not be used as
evidence that the final workflow fails.

For a clean Colab reproduction, use the top-level
`road_safety_dissertation_coding_clean.ipynb`. It checks out the validated
data-publication snapshot, verifies the published archive and runs
`python reproduce_dissertation.py`.
